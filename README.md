# Стиснення самплів подій методом найближчого сусіду (nearest neighbour, NN)
Є сампл подій. Із нього беремо частину подій (1/10), для кожної події шукаємо найближчого сусіда, об'єднуємо і отримуємо "стиснений" сампл. 
Рахуємо гістограми з використанням оригінального і стиснутого самплів, дивимось відхилення.
Повторюємо для нового стисненого самплу, який утворюється шляхом усереднення об'єднаних подій.
Робимо декілька ітерацій.

## одновимірний розподіл (штучний експоненційний)
```
python nn.py
```
## тривимірний розподіл (штучний експоненційний)
```
python nn3d.py
```
## тривимірний розподіл топ кварків із реального МК генератора (реальний фізичний), заповнюємо двовимірні гістограми за поперечним імпульсом і швидкісністю топ кварків
Для запуску треба завантажити МК події у форматі ROOT звідси:

https://cernbox.cern.ch/s/UmbXF1XxVrT4whQ

Потрібна лише директорія `MERGED/ntuples-mc/TTJets_TuneZ2_7TeV-madgraph-tauola` (1 ГБ). 
Після завантаження директорія `ntuples-mc/TTJets_TuneZ2_7TeV-madgraph-tauola` (чи посилання на неї) має бути в тій директорії, звідки запускається скрипт.
```
python nn3dtt.py
```
